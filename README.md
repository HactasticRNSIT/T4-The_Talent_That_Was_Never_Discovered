# HiddenSpark

A self-contained questionnaire web app for identifying unrealized student talent from multiple evidence sources.

## Run

Open `frontend/index.html` in a browser. The app stores saved drafts in `localStorage`.

## What It Includes

- Five-step student questionnaire
- Progress tracking and draft saving
- Multi-source evidence notes
- Curiosity, persistence, creativity, and opportunity scoring
- Final potential profile with recommended next steps
